Security

JWT + Role-based Access Control

كل طلب بيمر على Security Filter قبل ما يوصل للـ Controller.

1
العميل يبعت بيانات الدخول
Username وPassword لـ /api/auth/login
POST /api/auth/login
{ "username": "...", "password": "..." }
2
السيرفر يتحقق ويولد Token
Spring Security تتحقق من الداتا بيز وتولد JWT Token موقع
Response: { "token": "eyJhbGc..." }
3
كل طلب بعد كده يشيل الـ Token
في Authorization Header مع كل Request
Authorization: Bearer eyJhbGc...
4
السيرفر يتحقق من الـ Token والـ Role
JwtFilter يفحص التوقيع والصلاحيات قبل ما يعدّي الطلب
Role: USER → محدود / Role: ADMIN → كامل
